`.ksy`文件采用YAML格式编写，基本结构如下：
```YAML
meta: 
  id: my_format 
  title: "我的二进制格式" 
  file-extension: bin 
  endian: le # le=小端序, be=大端序 
seq: 
# 序列字段定义 
instances: 
# 实例字段定义
```
### meta-元数据部分：
每个 `.ksy` 文件都从 `meta` 声明开始，它定义了整个格式的元信息。
```YAML
meta: 
  id: png 
  title: "Portable Network Graphics" 
  file-extension: png 
  endian: be 
  imports: 
  - /common/utf8_string 
  - /common/ipv4_address
```
-  `id`: 格式唯一标识符（小写字母+下划线）
- `title`: 格式描述
- `file-extension`: 文件扩展名
- `endian`: `le`（小端）或 `be`（大端）
- `imports`: 导入其他.ksy文件

### **seq部分** - 序列字段（按顺序读取）
紧接着，你需要定义顶层 `seq`（序列），这是解析器读取字节流的主入口。通常我们会为整个二进制文件创建一个顶层类型
```
meta:
  id: instruction_stream
  endian: be
seq:
  - id: magic
    type: u4
  - id: count
    type: u2
  - id: instructions
    type: instruction
    repeat: expr
    repeat-expr: count
```
- `seq` 中的每个字段是按顺序读取的。
    
- `id` 是字段名，会在生成的对象中作为属性。
    
- `type` 可以是内建类型，也可以是另一个用户自定义类型

### 基本数据类型 —— 指令的最小砖块

Kaitai Struct 提供的内建类型足以描述任何标量：

|类型|含义|
|---|---|
|`u1`, `u2`, `u4`, `u8`|无符号整型，1~8 字节|
|`s1`, `s2`, `s4`, `s8`|有符号整型|
|`f4`, `f8`|IEEE 浮点|
|`b1`..`b8`|位宽（必须用在位域上下文中）|
|`str`|字符串（需指定 `encoding` 和 `size` 或终止符）|
|`bytes`|原始字节序列（需指定 `size`）|

###  复合类型与命名空间
把指令的各个部分抽象成独立类型，然后在父类型中引用它们。

```yaml
types:
  register:
    seq:
      - id: value
        type: u1
        enum: registers   # 映射到枚举

  instruction:
    seq:
      - id: opcode
        type: u1
        enum: opcodes
      - id: operands
        type: operands_group
        # 根据 opcode 动态选择结构（见第6节）
```
### 枚举 —— 赋予数字意义
指令的助记符、寄存器名称、条件码都适合用枚举。
```yaml
enums:
  opcodes:
    0x10: add
    0x20: sub
    0x30: load
    0x40: store
  registers:
    0x00: r0
    0x01: r1
    0x02: r2
    0x03: sp
```
使用时只需在字段上指定 `enum: opcodes`，生成的解析器就会自动将数字转换为字符串常量。

### 位域 —— 精确定义标志位与变长操作码
位域用 `b1..b64` 类型，并且必须放在 `seq` 里，通过 `type: bX` 和 `doc` 描述。解析器会逐位读取，遵循字节序（但位顺序永远是“先读取的字节的高位是字段的高位”，具体的位布局与字节序相关，通常大端模式下高位在前）。
