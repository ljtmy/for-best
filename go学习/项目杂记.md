### 结构体
```go
结构体（struct）

  type Todo struct {
      ID    int       // 字段名大写 = 公开（exported），其他包可访问
      title string   // 小写 = 私有（unexported），仅本包内可用
  }
```

 Go 没有 class，用 struct + 方法组合实现面向对象

### **JSON 标签**

  `json:"id"`
  告诉 encoding/json 包序列化时用什么字段名。Todo.ID → JSON 里变成 "id"。没有标签的话会用大写的 ID。

### 值接收者 vs 指针接收者

```go
  // 值接收者：不修改原对象，只读
  func (t Todo) String() string { ... }

  // 指针接收者：要修改原对象
  func (t *Todo) Toggle() { ... }
  规则：要修改 struct 的字段，必须用 *Todo。String() 只读所以用值接收者也可以，但习惯上保持一致。
```

### 构造函数
 
```go

  func NewTodo(id int, title string) *Todo {
      return &Todo{...}
  }
```
  Go 没有构造函数语法，约定用 NewXxx 函数，返回指针。这样调用方不用关心值还是引用。

### String() 方法 —— 接口隐式实现

```go
  func (t *Todo) String() string { ... }
  实现了 fmt.Stringer 接口：
  type Stringer interface {
      String() string
  }
```
  之后 fmt.Println(todo) 会自动调用 String() 输出。不需要写 implements 关键字，有这个方法就自动满足接口——这是 Go的核心设计哲学。
