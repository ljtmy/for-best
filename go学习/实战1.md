### 前置知识：
#### Go的并发模型：Goroutine与Channel

##### Goroutine：轻量级线程
Goroutine是Go并发编程的核心，通过`go`关键字启动，其栈空间初始仅2KB（可动态扩展），远小于操作系统线程（通常1MB）。

示例：并发执行函数

```go
package main

  

import (

    "fmt" //用于格式化输入输出

	    "time" //提供时间相关功能，这里使用 `Sleep` 暂停执行。

)

  

func say(s string) {

    for i := 0; i < 5; i++ {

        time.Sleep(100 * time.Millisecond) //让当前 goroutine 暂停 100 毫秒

        fmt.Println(s)

    }

}

func main() {

    go say("world") // 启动goroutine

    say("hello")    // 主goroutine

}
```
**输出：**
```bash
world
hello
hello
world
world
hello
hello
world
world
hello
```

##### Channel：安全通信
Channel用于goroutine间通信，避免共享内存导致的竞态条件
```go
package main

  

import (

    "fmt"

)

  
/*- 定义一个名为 `producer` 的函数，接收一个只发送（send-only）的通道 `ch`，通道内元素类型为 `int`。`chan<-` 表示该通道只能用来写入数据。*/
func producer(ch chan<- int) {

    for i := 0; i < 5; i++ {

        ch <- i
/*- 将 `i` 的值发送到通道 `ch` 中。如果通道缓冲已满，这里会阻塞直到有空间；由于后面会创建缓冲容量为 3 的通道，生产者发送前三次不会阻塞，之后可能因缓冲区满而短暂等待。*/
    }

    close(ch) //关闭通道 ch。关闭后不能再向通道发送数据，但接收方还可以继续读取已缓冲的数据

}

func consumer(ch <-chan int) {

    for num := range ch {

        fmt.Println("Received:", num)

    }

}

func main() {

    ch := make(chan int, 3) // 缓冲channel

    go producer(ch)

    consumer(ch)

}
```
