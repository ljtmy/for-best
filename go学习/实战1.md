### 前置知识：
#### Go的并发模型：Goroutine与Channel

##### Goroutine：轻量级线程
Goroutine是Go并发编程的核心，通过`go`关键字启动，其栈空间初始仅2KB（可动态扩展），远小于操作系统线程（通常1MB）。

示例：并发执行函数

```go
package main

  

import (

    "fmt" //用于格式化输入输出

	    "time" //提供时间相关功能，这里使用 `Sleep` 暂停执行。

)

  

func say(s string) {

    for i := 0; i < 5; i++ {

        time.Sleep(100 * time.Millisecond) //让当前 goroutine 暂停 100 毫秒

        fmt.Println(s)

    }

}

func main() {

    go say("world") // 启动goroutine

    say("hello")    // 主goroutine

}
```
**输出：**
```bash
world
hello
hello
world
world
hello
hello
world
world
hello
```
