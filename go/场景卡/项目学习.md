下面这 3 个概念是 Gin 入门的核心。

## 1. 什么是路由？

**路由就是“请求地址”和“处理函数”之间的对应关系。**

比如客户端访问：

```http
GET /users
```

服务器需要知道：

```text
当有人访问 GET /users 时，应该执行哪段代码？
```

这个对应关系就叫路由。

可以把路由理解成一张表：

|请求方法|请求路径|执行的处理逻辑|
|---|---|---|
|GET|`/users`|查询用户列表|
|POST|`/users`|创建用户|
|GET|`/users/:id`|查询某个用户|
|DELETE|`/users/:id`|删除某个用户|

注意：**路由不仅看路径，也看请求方法。**

所以：

```text
GET /users
POST /users
```

虽然路径都是 `/users`，但它们是两条不同的路由。

## 2. Gin 怎么注册路由？

在 Gin 中，注册路由就是告诉 Gin：

```text
某个 HTTP 方法 + 某个路径，要交给哪个函数处理。
```

最简单的例子：

```go
package main

import "github.com/gin-gonic/gin"

func main() {
    r := gin.Default()

    r.GET("/ping", func(c *gin.Context) {
        c.JSON(200, gin.H{
            "message": "pong",
        })
    })

    r.Run(":8080")
}
```

这段代码里：

```go
r.GET("/ping", ...)
```

就是注册了一条路由。

它的意思是：

```text
当客户端发送 GET /ping 请求时，执行后面的函数。
```

访问：

```http
GET http://localhost:8080/ping
```

返回：

```json
{
  "message": "pong"
}
```

---

Gin 常见的路由注册方式有这些：

```go
r.GET("/users", getUsers)
r.POST("/users", createUser)
r.PUT("/users/:id", updateUser)
r.DELETE("/users/:id", deleteUser)
```

其中：

```go
"/users"
"/users/:id"
```

是请求路径。

```go
getUsers
createUser
updateUser
deleteUser
```

是对应的处理函数。

完整一点的例子：

```go
package main

import "github.com/gin-gonic/gin"

func main() {
    r := gin.Default()

    r.GET("/users", getUsers)
    r.POST("/users", createUser)
    r.GET("/users/:id", getUserByID)

    r.Run(":8080")
}

func getUsers(c *gin.Context) {
    c.JSON(200, gin.H{
        "message": "获取用户列表",
    })
}

func createUser(c *gin.Context) {
    c.JSON(200, gin.H{
        "message": "创建用户",
    })
}

func getUserByID(c *gin.Context) {
    id := c.Param("id")

    c.JSON(200, gin.H{
        "message": "获取单个用户",
        "id":      id,
    })
}
```

这里注册了三条路由：

|路由|含义|
|---|---|
|`GET /users`|获取用户列表|
|`POST /users`|创建用户|
|`GET /users/:id`|获取某个用户|

其中：

```go
/users/:id
```

表示路径参数。

访问：

```http
GET /users/100
```

Gin 会把 `100` 取出来：

```go
id := c.Param("id")
```

## 3. handler 是什么？

**handler 就是处理请求的函数。**

当一个 HTTP 请求进来后，Gin 会根据路由找到对应的 handler，然后执行它。

例如：

```go
r.GET("/ping", func(c *gin.Context) {
    c.JSON(200, gin.H{
        "message": "pong",
    })
})
```

这里的匿名函数：

```go
func(c *gin.Context) {
    c.JSON(200, gin.H{
        "message": "pong",
    })
}
```

就是一个 handler。

它负责处理 `/ping` 这个请求。

---

handler 也可以单独定义：

```go
func pingHandler(c *gin.Context) {
    c.JSON(200, gin.H{
        "message": "pong",
    })
}
```

然后注册路由时使用它：

```go
r.GET("/ping", pingHandler)
```

这两种写法是一样的。

### handler 的标准形式

在 Gin 中，handler 通常长这样：

```go
func(c *gin.Context) {
    // 处理请求
}
```

或者：

```go
func xxxHandler(c *gin.Context) {
    // 处理请求
}
```

它的参数是：

```go
c *gin.Context
```

这个 `c` 很重要，可以理解成当前请求的上下文。

通过它可以做很多事：

```go
c.Param("id")          // 获取路径参数
c.Query("keyword")     // 获取查询参数
c.ShouldBindJSON(&req) // 获取 JSON 请求体
c.GetHeader("token")   // 获取请求头
c.JSON(200, data)      // 返回 JSON 响应
```

## 用一句话串起来

Gin 的工作流程可以理解为：

```text
客户端发送 HTTP 请求
        ↓
Gin 根据 Method + Path 找到路由
        ↓
路由匹配到对应 handler
        ↓
handler 处理请求
        ↓
handler 返回响应
```

比如：

```go
r.GET("/hello", helloHandler)
```

意思就是：

```text
如果收到 GET /hello 请求，就执行 helloHandler 函数。
```

完整示例：

```go
package main

import "github.com/gin-gonic/gin"

func main() {
    r := gin.Default()

    // 注册路由
    r.GET("/hello", helloHandler)

    r.Run(":8080")
}

// handler：处理请求的函数
func helloHandler(c *gin.Context) {
    c.JSON(200, gin.H{
        "message": "hello gin",
    })
}
```

访问：

```http
GET http://localhost:8080/hello
```

返回：

```json
{
  "message": "hello gin"
}
```

核心记住这句话就可以：

```text
路由决定“哪个请求由谁处理”，handler 就是“真正处理请求的函数”。
```
