# 协程

## 一句话
> Goroutine 是一种**由 Go 运行时（Runtime）自行管理的轻量级线程**（又称用户态线程）。

## 代码
```go
// 可运行的最小示例
package main

import (
	"fmt"
	"time"
)

func printTask(name string) {
	for i := 1; i <= 3; i++ {
		fmt.Printf("任务 %s 正在执行: %d\n", name, i)
		time.Sleep(100 * time.Millisecond) // 模拟耗时操作
	}
}

func main() {
	// 在函数调用前加一个 "go" 关键字，它就会在一个全新的 Goroutine 中异步运行
	go printTask("A") 
	go printTask("B")

	// 为了防止主函数瞬间结束导致协程来不及运行，这里先粗暴地睡一秒 (这是个伏笔)
	time.Sleep(1 * time.Second)
	fmt.Println("主函数执行完毕")
}
```

## 问题
- **Q1:加了go关键字的几条语句执行时有无规律？**
	A：这几条语句的执行顺序并没有规律，核心原理跟底层的GMP调度模型有关
- **Q2：将demo中的sleep语句去除后，直接执行到了fmt.Println("主函数执行完毕")，为什么？**
	A: main()函数不仅是函数的入口，go运行时会为它创建一个goroutine，这是主协程，程序的生命周期与主协程的生命周期挂钩，若子协程还未执行完主协程就执行完成了，程序就直接终结了
