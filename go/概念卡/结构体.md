# 结构体

## 一句话
>结构体就是一组字段（Field）的集合。它允许你将不同类型的数据绑定在一起，形成一个新的、有明确业务含义的自定义数据类型。

## 代码锚点
```go
// 结构体定义与声明
type User struct {
    ID       int
    Name     string
    IsActive bool
}
//初始化结构体的三者方法
u1 := User{
    ID:   1,
    Name: "Gopher",
    // IsActive 自动为 false
}

u2 := User{2, "Alice", true}

//`new(User)` 会分配内存，并将所有字段初始化为零值，返回的是指向该结构体的指针 `*User`。
u3 := new(User)
u3.ID = 3
u3.Name = "Bob"
```

## 进阶特性
- 要点1 ：**匿名嵌套**
  - Go 语言没有继承（Inheritance）。要想复用代码，Go 使用的是**组合 (Composition)**。如果一个结构体内嵌了另一个结构体且没有给出字段名，那么内部结构体的字段会自动“提升”到外部结构体上。
```go
  type Address struct {
    City string
}

type Employee struct {
    Name string
    Address // 匿名嵌套
}
// 调用时可以直接使用 emp.City，而不需要 emp.Address.City
```
- 要点2： **结构体标签**
  - 这是 Go 语言极其强大的反射特性应用。你可以在字段后加反引号定义 Tag，常用于 JSON 序列化、数据库 ORM 映射或表单验证。
```go
  type Product struct {
    Name  string  `json:"product_name" db:"name"`
    Price float64 `json:"price"`
}
```
- 要点3： **结构体比较**
  - 如果结构体的**所有字段都是可比较的**（例如基本类型），那么这两个结构体就可以使用 `==` 直接比较是否相等。但是，如果结构体内部包含了切片（Slice）、字典（Map）或函数等不可比较的类型，使用 `==` 会直接导致编译报错！

## 我的理解
go语言不是面对对象的，通过结构体来实现面向对象中的概念

## 常见坑
- **指针接收者 vs 值接收者**：若要在方法内部真实地修改结构体的数据，必须使用指针接收者 。若使用值接收者，Go 在调用方法时只会复制一份结构体，修改只会停留在副本上 。
