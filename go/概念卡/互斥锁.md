# 互斥锁

## 一句话
>**互斥锁（Mutex）** 是 `sync` 包提供的最基础的同步原语，用于保护共享内存免受并发访问导致的数据竞争。

## 代码
```go
package main

import (
	"fmt"
	"sync"
)

// 定义一个安全的计数器结构体
type SafeCounter struct {
	count int
	mu    sync.Mutex // 给计数器配一把专属的互斥锁
}

// Increment 增加计数器的方法
func (c *SafeCounter) Increment(wg *sync.WaitGroup) {
	defer wg.Done() // 确保离开时通知 WaitGroup 任务完成

	c.mu.Lock()         // 1. 进门，反锁！其他试图修改 count 的协程在此处排队阻塞
	defer c.mu.Unlock() // 2. 核心素养：无论发生什么，离开时必须解锁！

	c.count++           // 3. 安全地修改共享数据
}

func main() {
	counter := SafeCounter{count: 0}
	var wg sync.WaitGroup

	// 启动 1000 个 Goroutine 并发执行累加操作
	for i := 0; i < 1000; i++ {
		wg.Add(1)
		go counter.Increment(&wg)
	}

	wg.Wait() // 死等所有协程干完活
	fmt.Printf("预期的累加结果: 1000，实际最终结果: %d\n", counter.count)
}
```

## 核心要点
- 要点1：var mu sync.Mutex 声明后即可直接使用，无需初始化。
- 要点2： Lock()与Unlock() 必须成对
